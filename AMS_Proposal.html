Executive Summary

Project Overview

A single, unified platform to digitise and standardise all internal audits across the Bank

📋

The Problem

DCCB currently conducts Branch Audits and PACS/Mandali Audits entirely on paper registers with fixed printed questions, free-text answers, and manual follow-up of rectification reports. There is no central planning calendar, no structured risk scoring, no digital compliance tracking, and no MIS visibility for the Head of Internal Audit (HIA) or the Board.

🎯

Our Solution

A fully configurable, metadata-driven Audit Management System that digitises the complete audit lifecycle — Annual Planning, Field Execution, Compliance Tracking, HIA Review, and Audit Closure — with dynamic templates, workflows, and role-based access that the Bank can modify without any code changes.

Core Architecture

3 Dynamic Engines

The "configuration over code" philosophy — change everything without a developer

⚙

Dynamic Template Engine

Metadata-driven form renderer. Template → Section → Field tree. 20+ field types including repeatable grids, computed fields, evidence capture. Versioning ensures historical audits remain reproducible. Import/export as JSON. Preview mode before publish.

🔁

Dynamic Workflow Engine

Configurable state machine for approvals. Ordered stages with roles, SLA, conditions. Conditional routing (e.g. high-risk → extra approval). Parallel stages. Delegation & substitution. Auto-escalation on breach. Used for plan approval, audit review, and compliance verification.

🛡

Dynamic RBAC Engine

User → Role → Permission + Data Scope. Granular module/screen/action permissions. Field-level access restrictions. Row-level security (own branch, zone, all). Role-based dashboards & menus. Admin creates new roles via checklist matrix — no code release.

Platform Features

Advanced Platform Capabilities

Beyond audit — enterprise-grade system management, automation, and security

📋

Immutable Audit Log

System-wide activity trail that records WHO did WHAT action on WHICH record, WHEN the event triggered. Stores full before/after values for every create, update, delete, approve, and override action across all modules. No hard deletes — every record is soft-deleted with timestamp and user attribution. Fully queryable by Admin and HIA for internal control and regulatory compliance. The AMS is itself 100% auditable.

Tracked Events: Data changes, workflow actions, configuration changes, login/logout, permission modifications, template publishes
✅

Task Management System

A complete task manager integrated into the AMS. Admins, HIA, and managers can create tasks and assign them to any user or role. Tasks carry status (Pending / In Progress / Completed / On Hold), priority, deadline, description, attachments, and comments thread. Supports task dependency linking — Task B cannot start until Task A is completed. Automated reminders via in-app, email, SMS, and WhatsApp as deadline approaches.

Key Features: Create & assign, status tracking, comments/discussion, dependency linking, deadline reminders, bulk assignment, task templates for recurring activities
🏗

Pipeline Builder (Automated Workflow Scheduler)

A powerful visual pipeline designer where you can build end-to-end automated workflows step-by-step. Each pipeline consists of multiple stages that trigger sequentially or in parallel. Define what happens at each step, set date-time scheduling, and configure what event triggers the next step. If any step is missed or forgotten, the system sends direct notifications to the assignee and supervisor automatically.

Pipeline Example: Annual Audit Pipeline — Step 1: Generate Plan, Step 2: Notify Auditors, Step 3: Wait for Completion, Step 4: If overdue → Escalate, Step 5: HIA Review, Step 6: Compliance Window, Step 7: Closure Certificate
⏰

Pipeline — Smart Scheduling & Reminders

Every step in a pipeline can have its own date and time schedule. Configure exactly when a step should start, its deadline, and how much time before the deadline the reminder should fire (e.g. 2 days before, 1 hour before). Notifications escalate — first reminder to assignee, second reminder + copy to supervisor, third reminder → auto-escalation to HIA. Once a pipeline is set up once, it runs automatically for the entire financial year — auto-generating audit plans, assigning auditors, and triggering templates on schedule.

Reminder Channels: In-App Bell, Email, SMS, WhatsApp (configurable per pipeline)
⚙

Company Settings (Admin Control Panel)

A comprehensive central settings panel where Bank administrators manage every system-wide configuration. Control invoice numbering with custom prefixes (e.g. AUD/2026-27/001), document formatting with letterhead and logo upload, prefix rules for audit IDs, observation IDs, and closure certificates. Set financial year defaults, working hours, timezone, language preferences, and holiday calendar. Everything that involves numbering, formatting, or system-wide defaults is managed from one place — no developer needed.

Sections: General Info, Numbering & Prefix Engine, Document Templates, Financial Year, Language & Regional, Security Policies, Notification Defaults
💵

GST / SGST / CGST / IGST Entry & Tax Module

A dedicated GST taxation module integrated into the AMS. Admin can configure tax rates (CGST, SGST, IGST, Cess), the Bank's GSTIN number, and HSN/SAC codes — all from the admin panel. Any audit-related expense, service charge, or invoice generated in the system automatically computes taxable value + CGST + SGST (intra-state) or IGST (inter-state) with a full editable tax breakdown. A monthly/quarterly GST summary report (taxable value, CGST, SGST, IGST totals) can be exported to Excel/PDF — ready for GSTR-1/3B filing data. Additionally, GST compliance checks (GST registration, GSTR filing status, input tax credit verification) can be added as configurable questions in Branch/PACS audit templates.

Key Features: Tax Rate Configuration (CGST/SGST/IGST/Cess), GSTIN & HSN/SAC Setup, Auto Tax Calculation with Editable Breakdown, GST Ledger per Transaction, GSTR-Ready Summary Reports (Excel/PDF), GST Compliance Audit Questions
🔒

IP-Based Login & Global Configuration

IP-Based Login Restriction: Restrict system access to specific IP ranges — whitelist bank branch IPs, head office network, or specific subnets per user/role. If an IP changes mid-session, the user is auto-logged out. Perfect for ensuring auditors can only login from branch locations.

Global Configuration Manager: One central panel to configure which features trigger when. Set event conditions, time-based triggers, threshold-based alerts, and enable/disable entire feature modules. All configuration changes are logged in the Audit Log for traceability.
