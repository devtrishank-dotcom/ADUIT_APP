Log in with your Employee Code and password at the login screen.

Admin

2. Administrator Guide

2.1 Master Data

Menu: Admin → Masters. Manage Branches, PACS, Financial Years and Audit Types. Keep statuses active/inactive accurate — planning and auto-generate use only active records.

2.2 Template Builder (no-code audit formats)

1
Go to Admin → Templates → New Template, pick the Audit Type, save.
2
Open the Template Builder. Add sections and fields (15 types: text, number, currency, %, date, dropdown, Yes/No, grid, file, signature…).
3
For dropdowns, bind a shared Option List (e.g. Compliance Status: Complied / Partially Complied / Not Complied / Not Applicable).
4
Mark fields Mandatory, add visibility rules (show field only if another = a value), and attach Value Statements (guidance text, bilingual).
5
Set Risk Scoring: field weight + points per option + scoring bands.
6
Use Registers Checklist grids to reproduce the 20 Accounts registers / 18 Loan registers / PACS register list.
7
Click Publish. New audits use the new version; in-progress/closed audits keep their old version.

2.3 Option Lists, Value Statements & Risk Config

Edit shared dropdowns, bilingual guidance statements and risk bands under their respective Admin menu items. Changes apply to new template versions.

2.4 Workflows

Menu: Admin → Workflows. Add / reorder stages, set the actor role, allowed actions, SLA and conditional routing (e.g. only for High risk).

2.5 Roles & Permissions (RBAC)

1
Admin → Roles → New Role, name it.
2
Tick permissions in the module × action matrix (view / create / edit / approve / export…).
3
Set the Data Scope (All / Zone / Branch / PACS / Own). Save — immediately assignable, no deployment.

2.6 Users & Notifications

Menu: Admin → Users to create users and assign roles. Admin → Notifications to edit notification templates (recipients, channel, timing).

Planning

3. Audit Planner Guide

1
Create the annual plan: Planning → New Plan → choose Financial Year.
2
Auto-generate creates one item per active branch (Branch Audit) and per active PACS (PACS Audit).
3
Or Add Item manually: entity, audit type, assigned auditor, priority, audit period, planned dates.
4
Edit (pencil) or Reschedule (calendar) an item; reschedule captures a reason and marks status Rescheduled.
5
Start an item to create the audit instance and hand it to the auditor.
6
Submit for Approval (only Draft plans) → HIA approves from the plan approval inbox.
Tip: only Draft plans can be submitted. If submit is blocked, check the plan's status shown in the selector.
Execution

4. Auditor / Branch Manager Guide

1
Open My Audits — filter by status (Not Started / In Progress / Submitted / Returned / Approved / Closed).
2
Open an audit to see the section wizard. Fill each section; mandatory fields are marked with *.
3
Answers auto-save; use Save & Continue to save manually. Evidence files can be attached per question.
4
Watch the Risk Score panel update live as you answer.
5
Raise Observation: the Observations panel auto-detects non-compliant answers (Not Complied / Partially Complied) — click Raise, or use Raise Observation for a manual one. Add title, severity and target date.
6
Review & Submit — fix any missing mandatory fields, then submit for review.
Digital sign-off: the sign-off section replaces the paper "Inspecting Officer's Signature" with a role-authenticated action and timestamp.
Compliance

5. Compliance Owner Guide

1
Open Compliance → My Observations. Each row shows severity, target date and days remaining (overdue rows are highlighted).
2
Click Respond (or open the observation).
3
Enter your rectification response, attach evidence, and choose the outcome: Fully Complied or Partially Complied.
4
Submit. The observation status becomes Complied or Partially Complied and awaits verification.
5
If the auditor/HIA rejects the response, the observation returns to Open and you can respond again.
Tip: the observation detail page shows the full compliance thread (responses, verifications, rejections) with dates and authors.
Review

6. HIA Review Guide

1
Open HIA Review — submitted audits are listed with their computed risk rating.
2
Open an audit to view all sections, scores, observations and attachments.
3
Take action: Approve, Return for Rework (with comments), or Escalate. Risk override requires a justification note (logged).
4
Verify compliance: in an observation, approve the response → Verified, reject → back to Open, or Accept Risk.
5
Use the portfolio dashboard for bank-wide heat-map, plan vs. actual, ageing and productivity; drill down to any audit.
Closure

7. Audit Closure Guide

1
Open Closure — audits that are Approved with all observations Verified / Accepted Risk appear in the ready list.
2
Click Generate to produce a system-numbered Closure Certificate (PDF) with digital signatures/timestamps.
3
Closed audits are locked. To correct something, use the permissioned Reopen action (logged in the activity trail).
Note: an audit cannot be closed until every observation is Verified or consciously marked Accepted Risk.

Help

9. Troubleshooting / FAQ

I cannot see a menu item

Menus are derived from your role's permissions. Ask the Administrator to grant the module's View permission.

"Only Draft plans can be submitted"

The selected plan is already Submitted/Approved. Create a new plan or select a Draft one.

The form fields are not editable / not saving

The audit may be Submitted or Closed (read-only). Only In Progress / Returned audits can be edited.

An observation does not appear for the Compliance Owner

The observation must be raised on a submitted audit, and the user's data scope must include that branch/PACS.

Session logged out automatically

Tokens expire for security. Log in again; if it persists, contact the Administrator.
